## What is the Massar Code?

The Massar Code is an identifier assigned to a student within the Massar system. It connects school records to the right person and may be requested in some administrative or account procedures.

It is not a password, but it can identify a student in certain contexts. Treat it as personal information, not as something to post on social media.

## Massar Code versus password

| Item | Purpose | How to handle it |
|---|---|---|
| Massar Code | Identifies the student in the system | Do not publish it; give it only to an official source |
| Password | Protects account access | Keep it secret and never share it |
| One-time code | Adds verification at sign-in | Never send it to anyone or photograph it |

Confusing these items causes errors and risks. Someone may ask for "just the Massar Code" while claiming to help, then combine it with other information. Do not give more than the official authority actually needs, and verify who you are dealing with.

## Who provides the code?

It is normally provided by the school or the relevant administration, in enrolment documents, a student card or an official message. It may also appear in some documents issued by the system.

Schools may use different methods, so do not rely on general instructions about exactly where the code appears. Ask your school which document is authoritative.

## If you lose the code

1. Check enrolment documents and official correspondence.
2. See whether it appears in a parent account or in a document issued by the school.
3. Contact the school and ask for the official procedure.
4. Do not use "generator" or "recovery" sites that ask for your username or password.

If the code is linked to an account, do not create a new account without guidance from the school. Duplicate records can create confusion later.

## Protecting the code

- Do not post it in comments or chat groups.
- Do not send it to someone offering to "extract grades".
- Do not store it in notes on a shared phone.
- Do not photograph a document containing it alongside other personal details.
- If you suspect it has leaked, tell the school promptly.

> [!WARNING] Never pay for official information
> Obtaining a Massar Code or recovering an account is not a paid service offered by middlemen. If someone asks for money, stop and check the official channel.

## The code and privacy

The Massar Code may reveal that a person is a student at a particular school, and it may be combined with other data. Do not treat it as an ordinary number. Share it only with people who are entitled to it, within an official procedure.

## Summary

The Massar Code is an important identifier, but it is neither a password nor a substitute for one. Get it from your school, keep it safe, and avoid middlemen or unofficial websites. If it is lost, the correct channel is the school.
